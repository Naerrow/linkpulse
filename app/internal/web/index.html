단축 링크 요청하기

  1. 아래에 줄이고 싶은 주소를 넣고 요청하기를 누릅니다.
  2. 요청 전용 확인 페이지로 넘어갑니다. 그 페이지 주소를 저장해 두세요.
  3. 운영자가 확인하면, 저장한 확인 페이지에 단축 링크가 나타납니다.

이메일 같은 개인정보는 받지 않습니다. 그래서 결과는 확인 페이지에서만 볼 수 있습니다.

대기 중인 요청

주소를 확인하고 승인하면 단축 링크가 만들어집니다. 요청한 사람은 자기 확인 페이지에서 결과를 봅니다. 직접 보내 주고 싶으면 승인 뒤 나오는 링크를 복사하세요. 주소는 일부러 클릭되지 않게 글자로만 보여 줍니다.

대기 중인 요청이 없습니다.

    내 링크 (최근 50개)
